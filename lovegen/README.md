# ImgGen

Статический сайт: генерация картинок на любые темы по текстовому описанию.
Без откровенного 18+ контента и без детей. Провайдеры: pollinations.ai (без ключа, safe-фильтр) и Hugging Face FLUX.1-schnell (свой бесплатный токен, хранится только в браузере).

## Публикация на GitHub Pages

1. Создай репозиторий на GitHub и загрузи `index.html` и `README.md`.
2. Settings → Pages → Source: Deploy from a branch → `main` / root → Save.
3. Через минуту сайт откроется по адресу `https://<твой-ник>.github.io/<репозиторий>/`.
