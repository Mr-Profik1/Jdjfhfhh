# LoveGen

Статический сайт: генерация романтичных картинок (объятия, поцелуи, прогулки) по текстовому описанию.
Только взрослые персонажи, одетые, без откровенного контента. Картинки идут через pollinations.ai с включённым safe-фильтром.

## Публикация на GitHub Pages

1. Создай репозиторий на GitHub и загрузи `index.html` и `README.md`.
2. Settings → Pages → Source: Deploy from a branch → `main` / root → Save.
3. Через минуту сайт откроется по адресу `https://<твой-ник>.github.io/<репозиторий>/`.
