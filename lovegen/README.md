# ImgGen

Сайт генерации картинок на любые темы с регистрацией, историей и админ-панелью.
Без откровенного 18+ контента и без детей. Пользователи при регистрации подтверждают 18+ и согласие на модерацию запросов.

Файлы: `index.html` (сайт), `admin.html` (админка), `config.js` (настройки), `common.js`, `supabase.sql` (база).

## Настройка за 5 минут

1. Создай бесплатный проект на https://supabase.com (New project).
2. SQL Editor → New query → вставь весь `supabase.sql` → Run.
3. Project Settings → API: скопируй **Project URL** и ключ **anon public** в `config.js`
   (ключ `service_role` никому не показывай и в код не вставляй).
4. Authentication → Providers → Email: для быстрых тестов выключи **Confirm email**
   (позже можно включить обратно, тогда после регистрации нужно подтвердить почту).
5. Включи GitHub Pages: репозиторий → Settings → Pages → `main` / root → Save.
6. Открой `https://<ник>.github.io/<репозиторий>/lovegen/`, зарегистрируйся.
7. Сделай себя админом: в SQL Editor выполни
   `update public.profiles set role = 'admin' where email = 'твоя@почта';`
   и открой `/lovegen/admin.html`.

## Что умеет админка

Статистика, просмотр всех генераций с запросами и автором, удаление картинок,
блокировка и разблокировка пользователей. Пароль админа задаётся в Supabase при регистрации, в коде его нет.

## Ключ Hugging Face

Каждый пользователь может вставить свой бесплатный токен на сайте (хранится только в его браузере).
Не добавляй токены в репозиторий: он публичный. Без ключа работает Pollinations.
