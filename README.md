# LiteDroid

Лёгкий запускатор Android-x86 9.0 для слабых Windows-ноутбуков (4 ГБ ОЗУ). Внутри QEMU, а настройки уже подобраны: 1 ГБ памяти, 2 ядра, небольшой виртуальный диск.

## Как пользоваться

1. Скачайте `LiteDroid-win64.zip` из раздела **Releases** и распакуйте **целиком** (папка `qemu` должна лежать рядом с `LiteDroid.exe`).
2. Запустите `LiteDroid.exe`. При первом запуске он скачает образ Android-x86 9.0 (около 900 МБ).
3. В меню выберите **Installation** и поставьте Android на виртуальный диск (шаги выводятся в окне программы).
4. После установки ответьте `y`, и дальше Android будет запускаться с диска.

## Важно

- **Скорость.** Без аппаратной виртуализации QEMU работает очень медленно. Включите в BIOS Intel VT-x (если есть), а в Windows компонент **Платформа низкоуровневой оболочки Windows** (Windows Hypervisor Platform): Win+R, `optionalfeatures`.
- **Google Play** в образ не входит: он лицензируется Google. Официальный Android-x86 9.0 идёт без сервисов Google. Если нужен Play Store, скачайте образ, где он уже есть (например, PrimeOS или BlissOS с GApps), положите его в папку `data` под именем `custom.iso`, и LiteDroid будет использовать его вместо официального. Такие образы тяжелее, на 4 ГБ они могут тормозить.
- Для Black Russia и Oxide на слабом железе обычно лучше работает готовый LDPlayer 4.
- Проект не проверялся на реальном железе, поэтому возможны ошибки.
